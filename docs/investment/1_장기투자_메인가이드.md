## 이 문서의 역할

이 문서는 부부의 **95%의 자산을 운용할 장기 시스템**을 다룬다.

- **수동적 인덱스 투자** (자동화, 감정 차단, 평생 유지)
- 부부 합산 절세 계좌를 통한 정기 적립
- 한 번 셋업하면 매월 5분 이상 신경 쓸 일 없음

개별 종목 분석(LS일렉트릭 같은 케이스)은 **별도 문서 "개별 종목 분석 도구"** 참고.

## 1. 왜 — 통계가 말하는 사실

### 1.1 보유 기간이 모든 것

S&P 500 (1970~2020년, 배당 포함):

| 보유 기간 | 손실 확률 | 연평균 총수익률 |
|---|---|---|
| 1년 | 약 20% | 변동 큼 |
| 5년 | 약 15% | — |
| 15년 이상 | **0%** | 51년 평균 **+10.74%** |

→ 장기투자가 통계적으로 가장 강력한 알파. 매수 타이밍보다 **안 파는 능력**이 결정 변수.

### 1.2 통제 가능한 것에만 집중

| ✅ 100% 통제 가능 | ❌ 통제 불가능 |
|---|---|
| 안 파는 능력 | 종목 선택 결과 |
| 세금 효율 | 시장 타이밍 |
| 분산 | 단기 변동성 |
| 비용 최소화 | 외부 충격 |
| 부부 합의 룰 | 다른 사람의 수익률 |

이 시스템은 ✅ 5가지를 모두 자동화하는 데 초점.

### 1.3 신혼부부의 가장 큰 알파

**개인이 아니라 부부 단위로 절세 계좌를 운영하면 한도가 2배**가 됨. 이게 신혼부부의 최대 무기.

| 항목 | 1인 한도 | 부부 합산 |
|---|---|---|
| 연금저축 | 600만 원 | **1,200만 원** |
| IRP 추가 | 300만 원 | **600만 원** |
| ISA | 연 2,000만 원 | **연 4,000만 원** |
| 연 환급액 (총급여 5,500만 이하) | 148.5만 원 | **297만 원** |
| 연 환급액 (총급여 5,500만 초과) | 118.8만 원 | **237.6만 원** |

→ 부부 합산 연 1,800만 원 납입 시 즉시 확정 환급 약 297만 원/년. 어떤 주식보다 확실.

## 2. 시작 전 토대

투자 매수 버튼을 누르기 전에 채워야 할 것.

### 2.1 비상금 (최우선)

| 항목 | 내용 |
|---|---|
| 목표 | 부부 합산 월 생활비의 **3~6개월치** |
| 위치 | CMA, MMF, 파킹통장 |
| 원칙 | 절대 주식·ETF에 넣지 말 것 |

**왜?** 시장이 -30% 무너졌을 때 생활비가 부족해서 강제 매도하는 게 가장 큰 손실 패턴.

### 2.2 부부 통장 구조

| 항목 | 권장 구조 |
|---|---|
| 생활비 통장 | 공동 (각자 일정 금액 자동이체) |
| 비상금 통장 | 공동 1개 |
| 투자 통장 | 공동 목표용 + 각자 개인용 |
| 개인 용돈 통장 | 각자 별도, 서로 간섭 X |

**비율**: 공동 70% + 개인 30% 구조가 통계적으로 부부 갈등 최소.

## 3. 계좌 인프라 — 부부 합산 절세 계좌

### 3.1 어떤 계좌를 만들 것인가

각 계좌의 특성을 먼저 이해.

| 계좌 | 세제 혜택 | 인출 제약 | 위험자산 한도 | 용도 |
|---|---|---|---|---|
| **연금저축** | 세액공제 13.2~16.5% | 55세 전 16.5% 과세 | 100% | 노후 + 주식 ETF |
| **IRP** | 세액공제 13.2~16.5% | 55세 전 16.5% 과세 | **70%** | 노후 + 주식·채권 혼합 |
| **ISA** | 비과세 200~400만 원 | 3년 의무 보유 | 100% | 중기 (5~10년) |
| 일반 계좌 | 없음 | 자유 | 100% | 개별 종목 (LS일렉트릭 등) |

### 3.2 부부가 만들 계좌 목록

부부 각자 다음을 개설:

```
□ 연금저축 계좌 (증권사, 수수료 면제 상품)
□ IRP 계좌
□ ISA 계좌
```

→ 총 **부부 합산 6개 계좌**. 이게 평생의 인프라.

### 3.3 절세 계좌의 또 다른 강점: 리밸런싱이 무료

- **연금저축/IRP 안에서 매수·매도**: 모든 거래가 **과세 이연** (인출 시까지 세금 0)
- **ISA 안에서 매수·매도**: 손익 통산, 200~400만 원까지 비과세
- **일반 계좌**: ETF 매도 시 배당소득세 15.4%

→ 리밸런싱을 절세 계좌 안에서 하면 세금 0원. 절세 계좌를 먼저 채워야 하는 이유 추가.

## 4. 자산 선택 — 무엇을 살 것인가

계좌가 준비됐다. 이제 그 안에 무엇을 담을지 결정.

### 4.1 자산 배분 결정 (큰 그림)

#### 위험 자산 비율

부부의 **소득 안정성**에 따라 다름. 단순 공식: **(100 - 평균 나이)% 주식**.

| 부부 상황 | 주식 : 채권/현금 |
|---|---|
| 맞벌이 정규직 (안정성 최고) | 70~80 : 20~30 |
| 맞벌이 중 1명 비정규직 | 60~70 : 30~40 |
| 외벌이 정규직 | 50~60 : 40~50 |
| 프리랜서·자영업 | 40~50 : 50~60 |

#### 지역 분산

- **미국**: 60~70%
- **한국**: 10~20%
- **신흥국·기타**: 10~20%

이유: 1957년 이후 장기 데이터 기준 S&P 500이 KOSPI 압도. 단, 환위험 분산을 위해 국내 일부 보유.

### 4.2 구체적 ETF (한국 상장, 절세 계좌 가능)

#### 미국 S&P 500 (메인)

| ETF | 코드 | 총보수 | 특징 |
|---|---|---|---|
| TIGER 미국S&P500 (TR) | 360750 | ≈ 0.07% | 배당 자동 재투자 (복리 최대화) |
| KODEX 미국S&P500 | 379800 | ≈ 0.09% | 분기 배당 |
| RISE 미국S&P500 | 379780 | **0.087%** | 국내 최저 보수급 |

#### 미국 나스닥 100 (선택)

- TIGER 미국나스닥100 (133690)
- KODEX 미국나스닥100 (379810)

#### 한국 지수

- KODEX 200 (069500)
- TIGER 200 (102110)

#### 채권 (안정 자산)

- KODEX 단기채권 (153130) — 현금성
- KOSEF 국고채10년 (148070) — 중장기 국채

**환헤지 vs 비헤지**: 장기투자는 일반적으로 **비헤지(TR)** 선호. 환위험을 자연 분산으로 활용.

### 4.3 계좌별 운용 매핑

| 계좌 | 담을 내용 |
|---|---|
| **연금저축** (100% 위험자산 가능) | TIGER 미국S&P500 (TR) 100% |
| **IRP** (70% 한도) | 미국 S&P 500 60% + 채권 ETF 30% + 안전자산 10% |
| **ISA** | 미국 + 한국 ETF 혼합, 중기 목표 자금 |
| **일반 계좌** | LS일렉트릭 같은 개별 종목 (전체의 5~10% 이하) |

## 5. 실행 — 적립식 자동 매수

자산 배분이 정해졌다. 이제 매수.

### 5.1 DCA (적립식 매수) 원칙

- **매월 같은 날짜에 같은 금액**을 자동 매수
- 가격이 떨어지면 더 많이, 오르면 더 적게 사게 됨 (자동 평균화)
- **타이밍 잡으려 하지 말 것**. 통계적으로 DCA가 일시 매수보다 안정적
- 자동이체 + 자동매수 설정해두면 감정 개입 자체가 차단됨

### 5.2 자동화 셋업 절차

```
1. 월급통장 → 투자 통장으로 자동이체 (월급일 +1일)
2. 투자 통장 → 연금저축 / IRP / ISA 자동이체
3. 각 계좌 내에서 ETF 자동 매수 설정
   (증권사 앱에서 "정기 매수" 또는 "월 적립식" 기능)
4. 결과 알림 OFF (보면 손이 움직임)
```

### 5.3 권장 적립 금액 예시

부부 합산 절세 한도 풀가동 시:

| 항목 | 부부 각자 | 합산 |
|---|---|---|
| 연금저축 | 월 50만 원 | 월 100만 원 |
| IRP | 월 25만 원 | 월 50만 원 |
| **소계 (절세)** | **월 75만 원** | **월 150만 원** |
| ISA (여유 시) | 월 10~30만 원 | 월 20~60만 원 |

부부 합산 월 150만 원 = 연 1,800만 원 = 환급 약 297만 원/년.

## 6. 유지 관리 — 리밸런싱과 머니 데이트

자동화가 돌고 나면 할 일은 거의 없다. 단, 1년에 한 번은 점검.

### 6.1 리밸런싱이란

목표 자산 배분이 시장 변동에 따라 어긋날 때 원래 비율로 되돌리는 작업.

**예시**: 목표가 주식 70% / 채권 30%였는데, 상승장 후 85% / 15%가 됨.
- 그대로 두면 위험도 상승 → 다음 하락장 때 더 큰 손실
- 리밸런싱: 주식 일부 매도 + 채권 매수 → 자동으로 "비싸게 팔고 싸게 사기"

본질: **수익률 극대화가 아니라 위험 관리**. 그리고 강제 "고매도/저매수" 실행.

### 6.2 리밸런싱 방식 비교

| 방식 | 주기 | 장단점 |
|---|---|---|
| 시간 기반 | 연 1회 | 단순. 통계적으로 가장 무난 |
| 임계값 기반 | ±5% 이탈 시 | 효율적이지만 모니터링 필요 |
| **현금흐름 기반 (권장)** | 매월 적립금을 부족 자산에 우선 투입 | **세금 0원**, 매도 불필요 |

**부부 권장 조합**:
- 평소(매월): 적립금 비중을 부족 자산에 더 많이 배분 (현금흐름 기반)
- 연 1회(머니 데이트 때): 전체 점검, ±5% 이상 이탈 시 매매로 조정

### 6.3 연 1회 리밸런싱 실전

```
1. 현재 자산을 분류 (미국 주식 / 한국 주식 / 채권 / 현금)
2. 각 비중 계산
3. 목표 비중과 비교
4. ±5% 이상 이탈한 항목 식별
5. 절세 계좌 안에서 매수/매도 (세금 0)
6. 다음 12개월 자동이체 비율 조정
```

### 6.4 흔한 실수

- ❌ 너무 자주 함 (월별, 주별) → 거래 비용 누적, 효과 감소
- ❌ 시장이 무서워서 보수적으로 변경 → 시장 타이밍 잡기 = 통계상 손해
- ❌ 절세 계좌 외에서 적극적 매도 → 불필요한 세금
- ❌ 목표 비중 자체를 자주 바꿈 → 일관성 없는 운용

### 6.5 월간 머니 데이트

- 매월 정해진 날 1시간
- 항목: 자산 변화 점검, 다음 달 계획
- **이 자리에서만 투자 의사결정**
- 자동매수 정상 동작 확인

## 7. 부부 가드레일

### 7.1 임계값 룰 (사전에 정하기)

| 금액 | 의사결정 방식 |
|---|---|
| ~10만 원 | 각자 자유 |
| 10만 ~ 50만 원 | 사후 공유 |
| 50만 ~ 200만 원 | 사전 통보 (이의 없으면 진행) |
| 200만 원 이상 | **사전 합의 필수** |
| 500만 원 이상 | **사전 합의 + 24시간 숙고** |

→ 이 룰 하나로 충동 매수의 80% 차단.

### 7.2 30일 룰

- 새로운 종목 / ETF / 큰 결정 → **30일간 보류 후 재논의**
- 30일 후에도 같은 판단이면 실행
- "오늘 안 사면 놓친다"는 90% 거짓

### 7.3 거부권 (Veto)

- 부부 중 한 명이 명확히 반대하면 그 투자는 **무조건 보류**
- 설득하지 말 것. 시간이 답함.

### 7.4 통계적으로 피해야 할 행동

| 행동 | 이유 |
|---|---|
| 단타·스윙 매매 | 수수료·세금 누수, 시장 수익률 미달 |
| 레버리지 ETF (2X, 3X) | 변동성 끌림으로 장기 음(-)의 기대값 |
| 인버스 ETF | 시장 장기 상승 추세에 역행 |
| 테마 ETF의 "분산" 환상 | BIG3에 68% 몰린 ETF는 분산 효과 거의 없음 |
| 레버리지 빚투 | 변동성 견딜 능력 자체 소멸 |
| 유튜브·커뮤니티 종목 추천 | 누가 그 정보로 이득 보는지 불명 |
| 평단가 낮추기 (물타기) | 잘못된 판단에 자본을 더 투입 |
| 일봉 매시간 확인 | 단타 사고로 끌려감. 장기 투자자는 주봉/월봉 |

### 7.5 단일 종목 한도

- 단일 종목 비중 ≤ **전체 자산의 5~10%**
- 어떤 종목이든 이 룰 적용
- 개별 종목 분석은 별도 문서 참고

## 8. 정보 거르기

커뮤니티 / 유튜브 / 지인 추천 받았을 때 즉시 점검.

### 8.1 5가지 질문

1. **리스크 언급이 있는가?** 없으면 분석 아닌 호객.
2. **반증 가능한 주장인가?** "지속적 우상향" 같은 모호한 표현은 신호.
3. **누가 이득을 보는가?** 작성자의 포지션 방어일 가능성.
4. **이미 다 알려진 사실인가?** 커뮤니티 도달 정보 = 가격 반영 완료.
5. **시간 프레임이 일관되는가?** 장·단기 시나리오 혼용은 신호.

### 8.2 실전 검증 사례: 토스 커뮤니티 "전력주" 글

| 주장 | 판정 |
|---|---|
| "반도체보다 더 심한 전력 병목" | 반쯤 사실 — 이미 가격 반영 |
| "장기계약으로 단기 밸류에이션 둔감" | **거짓** — 조선·방산도 분기 30~40% 변동 |
| "외국인 안 들어와서 개인/ETF로 우상향" | **거짓** — 외국인 일일 수십만 주 매도 중 |
| "ETF 분산으로 한 분야 쉴 때 다른 분야 급등" | **거짓** — BIG3에 68% 몰림 |
| "전력은 차세대 주도섹터" | 반쯤 사실 — 컨센서스 = 가격 반영 |

5개 주장 중 사실 0, 반쯤 사실 2, 거짓 3. **리스크 언급 0개** → 분석 아닌 호객.

## 9. 부록

### 9.1 부부 자가 점검 체크리스트

#### 토대
- [ ] 비상금 3~6개월치 확보 (CMA/MMF/파킹통장)
- [ ] 부부 통장 구조 합의 (공동 70% + 개인 30%)

#### 계좌 인프라
- [ ] 부부 각자 연금저축 계좌 개설 (증권사, 수수료 면제)
- [ ] 부부 각자 IRP 계좌 개설
- [ ] 부부 각자 ISA 계좌 개설

#### 자산 배분
- [ ] 위험 자산 비율 합의 (부부 상황에 맞게)
- [ ] 지역 분산 비율 합의 (미국 / 한국 / 기타)
- [ ] 목표 비중 문서화

#### 자동화
- [ ] 월급통장 → 투자 통장 자동이체 설정
- [ ] 각 계좌에 자동매수 설정
- [ ] 결과 알림 OFF

#### 유지 관리
- [ ] 연 1회 리밸런싱 날짜 합의 (예: 매년 1월)
- [ ] 월간 머니 데이트 날짜 정하기

#### 부부 룰
- [ ] 임계값 룰 합의 (10/50/200/500만 원)
- [ ] 30일 룰 합의
- [ ] 거부권 룰 합의

#### 투자 행동
- [ ] 단타·레버리지·인버스·테마 ETF 금지 합의
- [ ] 단일 종목 5~10% 한도 합의
- [ ] 일봉 보지 않기 합의

### 9.2 개인투자자 손실 패턴 (해당 시 체크)

- [ ] 고점 추격 매수 (FOMO)
- [ ] 손실 회피 편향으로 손절 못 함
- [ ] 평단가 낮추려 물타기
- [ ] 단일 테마/종목 집중
- [ ] 같은 테마 ETF + 개별 종목 동시 보유를 "분산"으로 착각
- [ ] 단기 매매 반복
- [ ] 커뮤니티 글의 일방향 논리에 동조
- [ ] 절세 계좌 활용 없이 일반 계좌만 사용
- [ ] 환위험 무시 (한국 단일 통화 노출)
- [ ] 비상금 없이 전액 투자
- [ ] 일봉 차트 매시간 확인

### 9.3 용어

| 용어 | 뜻 |
|---|---|
| **DCA (Dollar Cost Averaging)** | 적립식 매수. 매월 같은 금액으로 정기 매수 |
| **리밸런싱** | 자산 비중이 목표에서 어긋날 때 원래 비율로 복원 |
| **TR (Total Return)** | 배당 자동 재투자형 ETF |
| **헤지 (환헤지)** | 환율 변동 위험을 제거 (비용 발생) |
| **과세 이연** | 세금 부과 시점을 미래로 미루는 것 (연금저축/IRP) |
| **위험자산** | 변동성이 큰 자산. 일반적으로 주식 |
| **안전자산** | 변동성이 작은 자산. 현금성·국채 |
