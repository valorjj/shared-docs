# 개별 종목 분석 도구

> 작성일: 2026년 5월 11일
> 부부 공유용 문서 — 보조 (개별 종목 분석)
> 본 문서는 일반 정보 제공 목적이며, 투자 자문이 아닙니다.

---

## 이 문서의 역할

이 문서는 부부의 **5%의 자산을 차지하는 개별 종목**을 다룬다.

- 펀더멘털, 공매도, 차트 등 능동적 분석 도구
- LS일렉트릭 같은 보유 종목 점검 방법
- 신규 종목 매수 시점 판단

**전체의 95%는 메인 가이드 (인덱스 자동화)**. 이 문서는 그 외 5%에만 적용.

---

## 솔직한 전제

장기 인덱스 투자자에게 종목 분석 도구는 **대부분 노이즈**다. 다음 두 가지 경우에만 가치가 있다.

1. **이미 개별 종목을 보유 중** (LS일렉트릭처럼) → 보유 점검용
2. **신규 매수 시 명백한 고점 회피** → 진입 시점 보조

매도 결정이나 신규 종목 선정의 주된 기준은 **펀더멘털**이지 차트가 아님. 차트는 "이미 정한 매수 종목의 진입 시점 도구" 정도.

## 1. 펀더멘털 분석 기초

종목을 평가하는 첫 번째 기준. 차트보다 우선.

### 1.1 핵심 4가지 지표

| 지표 | 뜻 | 해석 |
|---|---|---|
| **PER** (주가/주당순이익) | 이익 대비 주가 배수 | 10배 이하 저평가, 30배 이상 고평가 (업종별 차이) |
| **PBR** (주가/주당순자산) | 자산 대비 주가 배수 | 1배 이하는 청산가치 미달 |
| **ROE** (자기자본이익률) | 자기자본으로 얼마나 이익을 내는가 | 10% 이상 우수, 15% 이상 매우 우수 |
| **부채비율** | 부채/자본 | 100% 이하 안전, 200% 초과 주의 |

### 1.2 매출과 영업이익 추이

- **YoY (전년 동기 대비) 성장률**: 매출/영업이익이 안정적으로 증가하는가?
- **분기별 추이**: 계절성 있는 업종은 분기별 비교가 의미 있음
- **수주잔고**: 향후 매출로 전환될 계약 누적액 (B2B 기업에 중요)

### 1.3 애널리스트 컨센서스

- 여러 증권사 애널리스트의 평균 전망치
- **목표주가 평균** vs 현재가 비교 → 시장의 합의된 적정 가격
- **확인처**: 네이버 금융, 인베스팅닷컴, 한경 컨센서스

**중요**: 컨센서스보다 한참 위에 있는 주가는 **이미 미래 실적을 다 반영한 가격**.

## 2. 공매도 위험도 판단

### 2.1 두 가지 지표 구분 (헷갈리기 쉬움)

| 지표 | 의미 | 해석 |
|---|---|---|
| **공매도 거래대금 비율** | 당일 거래대금 중 공매도 % | 단기 매매 강도. 변동 큼 |
| **공매도 잔고 비율** | 상장주식수 대비 현재 공매도된 주식 % | **중장기 베어 베팅 정도. 핵심 지표** |

**예시 (LS일렉트릭)**:
- 5월 7일 공매도 거래대금 비율 16.67% → 그날 매매가 활발했다는 의미
- 공매도 **잔고** 비율이 5%를 넘는다면 → 헤지펀드가 누적으로 진지하게 베어 베팅

### 2.2 잔고 비율 위험도 가이드

| 잔고 비율 | 해석 |
|---|---|
| < 1% | 무시 가능 |
| 1~3% | 일반적 수준 |
| 3~5% | 주의 |
| **5~10%** | **명백한 베어 베팅 신호** |
| > 10% | 고위험. 펀더멘털에 심각한 우려 가능성 |

### 2.3 어디서 확인하나

- **KRX 정보데이터시스템**: https://data.krx.co.kr (무료, 공식)
  - 메뉴: 공매도 > 개별종목 공매도잔고 또는 종목별 공매도 거래
- **KRX 공매도 종합포털**: https://short.krx.co.kr
- **공매도 잔고 대량보유자 공시**: 상장주식수의 0.01% 이상 잔고는 공시 의무 (T+2 공시)
- **공매도 과열종목 지정 현황**: 매일 KRX에서 발표

### 2.4 공매도 잔고만 보면 안 되는 이유

- 공매도 잔고가 높아도 **펀더멘털이 강하면 결국 회복**됨
- 단, 잔고가 **빠르게 증가 중**이면 → 시장의 새 정보가 부정적임을 시사
- **잔고 증가 속도 + 절대 수준** 두 가지를 봐야 함

### 2.5 숏스퀴즈 환상 주의

- 숏스퀴즈는 실재하지만 드물고 예측 불가
- 펀더멘털 충격(실적 대폭 초과 등)이 트리거가 돼야 함
- "공매도 많으니까 곧 폭등할 것"은 **희망적 사고**. 통계상 공매도 많은 종목은 평균적으로 더 빠짐

### 2.6 외국계 창구 공매도의 진실

- 한국 시장에서 JP모건·모건스탠리·골드만 창구로 잡히는 공매도는 **자기 베팅이 아니라 글로벌 헤지펀드 중개**(프라임 브로커리지)인 경우 다수
- "JP모건이 우리 종목을 죽이려 한다"는 커뮤니티 서사는 사실관계가 단순하지 않음
- 진짜 누가 공매도하는지는 외부에서 알 수 없음

## 3. 차트 읽기: 이동평균선과 지지/저항

### 3.1 이동평균선이란

지난 N일간 종가의 평균을 선으로 연결한 것. 현재 가격이 그 평균보다 위/아래에 있는지로 추세 판단.

| 이동평균선 | 기간 | 누가 보는가 |
|---|---|---|
| **5일선** | 1주일 | 데이 트레이더, 초단기 |
| **20일선** | 1개월 | 스윙 트레이더 |
| **60일선** | 약 3개월 (분기) | 중기 투자자 |
| **120일선** | 6개월 (반기) | 중장기 투자자 |
| **200일선** | 약 1년 | 글로벌 표준, **장기 투자자** |

**장기 투자자에게 의미 있는 건 60일선 이상**. 5일선, 20일선은 단기 매매용이고 노이즈가 큼.

### 3.2 이동평균선이 곧 "동적 지지선/저항선"

- **상승 추세**: 주가가 이동평균선을 위에 두고 진행. 가격이 내려와도 이동평균선에서 반등하는 경우가 많음 → 그 선이 **지지선**
- **하락 추세**: 주가가 이동평균선 아래에 있음. 위로 올라가려 해도 이동평균선에서 다시 밀림 → 그 선이 **저항선**

**예시**: 어떤 주식이 60일선 위에서 움직이다가 60일선까지 떨어졌을 때 매수세가 들어와 반등 → 60일선이 지지선 역할.

### 3.3 정적 지지선/저항선

과거에 매매가 몰렸던 가격대.

- "30만 원 위로 못 뚫었다"가 여러 번 반복되면 → 30만 원이 **저항선**
- "20만 원 아래로 안 떨어졌다"가 반복되면 → 20만 원이 **지지선**

**중요**: 지지선이 한 번 뚫리면 그 다음에는 저항선으로 작용함 (역할 전환).

### 3.4 골든크로스 / 데드크로스

- **골든크로스**: 단기 이동평균선이 장기 이동평균선을 **위로** 돌파 → 상승 신호
  - 예: 60일선이 120일선을 위로 뚫음
- **데드크로스**: 단기 이동평균선이 장기 이동평균선을 **아래로** 돌파 → 하락 신호

**솔직한 한계**: 후행 지표. 신호가 나왔을 때는 이미 가격이 한참 움직인 뒤. 장기 투자자에겐 참고용.

### 3.5 이격도 (Disparity Ratio)

(현재 가격 / N일 이동평균선) × 100

- 100% = 이동평균선과 같음
- 110% = 이동평균선보다 10% 위 (단기 과열)
- **120일 이동평균선 이격도 100% 초과 = 과열 신호** (전문가 다수 의견)

이격도가 높을수록 단기 조정 가능성 ↑.

## 4. 차트 추세 확인

### 4.1 시간 프레임 선택

| 보는 사람 | 차트 종류 |
|---|---|
| 데이 트레이더 | 분봉, 일봉 |
| 스윙 트레이더 | 일봉, 주봉 |
| **장기 투자자** | **주봉, 월봉** |

**원칙**: 장기 투자자는 **일봉 보지 말 것**. 일봉을 보는 순간 단타로 끌려감.

### 4.2 추세 식별 (가장 단순한 방법)

| 패턴 | 추세 |
|---|---|
| 직전 고점보다 높은 고점 + 직전 저점보다 높은 저점 | **상승 추세** |
| 직전 고점보다 낮은 고점 + 직전 저점보다 낮은 저점 | **하락 추세** |
| 비슷한 고점 + 비슷한 저점 반복 | **횡보** |

### 4.3 거래량 (Volume) 확인

차트 하단의 막대 그래프. 가격 움직임의 "신뢰도"를 알려줌.

| 가격 + 거래량 | 해석 |
|---|---|
| 가격 상승 + 거래량 증가 | 강한 상승 (신뢰도 높음) |
| 가격 상승 + 거래량 감소 | 약한 상승 (의심) |
| 가격 하락 + 거래량 증가 | 강한 하락 (위험) |
| 가격 하락 + 거래량 감소 | 약한 하락 (반등 가능성) |

## 5. 장기 투자자의 5단계 종목 점검

신규 종목 또는 보유 종목 점검 시 항상 이 순서로:

```
1. 펀더멘털 점검
   - 매출/영업이익 성장률
   - PER, PBR, ROE
   - 애널리스트 컨센서스 목표가 vs 현재가

2. 52주 차트 위치 확인
   - 52주 최고가·최저가
   - 현재 위치 (신고가 부근이면 주의)

3. 이동평균선 점검 (60일선 / 120일선)
   - 주가가 이동평균선 위/아래?
   - 이격도 (특히 120일 이격도)

4. 거래량 추이
   - 매수세가 살아있는지

5. 공매도 잔고 비율
   - 헤지펀드의 누적 의견
```

이 5가지가 **모두 빨간불**이면 매수 보류. 한두 개만 빨간불이면 분할매수 고려.

### 5.1 차트의 역할 (다시 정리)

장기 투자자에게 차트의 역할:
- ✅ 명백한 단기 과열 회피 (이격도 120% 같은 상황)
- ✅ 신규 매수 시점을 며칠~몇 주 미루는 판단
- ✅ 분할매수 비율 조정
- ❌ "어떤 종목을 살지" 결정 → **펀더멘털로**
- ❌ "지금 팔지 말지" 결정 → **펀더멘털 훼손 시에만**
- ❌ 단기 가격 예측

**원칙**: 종목 선택은 펀더멘털로, 진입 시점은 차트로, 매도는 목표 달성 또는 펀더멘털 훼손 시.

## 6. 사례 학습: LS일렉트릭

> 부부의 첫 개별 종목 투자 사례. 위 도구들을 실제로 적용한 분석.

### 6.1 현재 포지션

| 항목 | 값 |
|---|---|
| 매수가 | 312,000원 |
| 현재가 | 약 300,000원 |
| 수량 | 6주 |
| 원금 | 약 1,860,000원 |
| 평가손실 | 약 -3.8% (≈ 7만 원) |

### 6.2 펀더멘털 분석

**긍정 요인**
- 26년 1Q 매출 1조3,766억 (+33.4%), 영업이익 1,266억 (+45.3%), 분기 사상 최대
- 수주잔고 5조6,000억 (+45% YoY), 초고압 변압기만 3조1,000억
- 북미 매출 +80% YoY, AWS 등 빅테크 누적 수주 5,000억+
- 26년 컨센서스: 영업이익 6,376억 (+50%)

**부정 요인**
- PER 83배, PBR 19.6배 (매우 높음)
- 애널리스트 21명 평균 목표가 **215,181원** (현재가 대비 **-31%**)
- 빅3 동시 증설 → 공급과잉 리스크

→ **펀더멘털: 좋음. 밸류에이션: 매우 높음.** 컨센서스가 현재가의 -31%라는 건 이미 비싸다는 시장 합의.

### 6.3 공매도 분석

- 외국인 일일 -40~-130만 주 순매도
- 외국인 지분율 20.5% → 18.7%로 감소
- 공매도 거래비중 16~17% (단기 매매 강도 매우 높음)

→ 공매도 **잔고** 비율 확인 필요 (KRX 데이터). 거래 비중만으로는 판단 부족.

### 6.4 차트 분석

매수 시점 (4월 말~5월 초) 차트 상태:
- 액면분할 직후 7거래일 연속 신고가
- **120일 이격도 100% 초과** (전형적 단기 과열)
- 52주 신고가 부근

→ **차트만 봤어도 분할매수로 진입했어야 할 상황**. 한꺼번에 6주 일시 매수는 명백한 단기 과열 지점.

### 6.5 종합 진단

| 점검 항목 | 결과 |
|---|---|
| 펀더멘털 | ✅ 강함 |
| 밸류에이션 | ❌ 매우 높음 (컨센서스 -31%) |
| 52주 위치 | ❌ 신고가 부근 |
| 120일 이격도 | ❌ 100% 초과 (과열) |
| 거래량 | △ 변동 큼 |
| 공매도 거래비중 | ❌ 16~17% (높음) |

**5개 중 4개 빨간불**. 차트 도구를 알았다면 매수 보류 또는 분할매수가 정답이었던 케이스.

### 6.6 교훈

| 교훈 | 적용 |
|---|---|
| 액면분할 + 7일 연속 신고가 직후 매수 = 통계적으로 고점 매수 패턴 | 새 종목 매수 전 30일 룰 + 5단계 점검 |
| 펀더멘털 우수 ≠ 매수 적정가 | 펀더멘털과 밸류에이션은 분리 분석 |
| 일시 매수 X, 분할매수 O | 신규 종목은 무조건 3~5회 분할 |
| 일봉 차트가 아니라 월봉 차트로 봐야 | 장기 투자자는 주봉/월봉만 |

### 6.7 부부 합의 결론

- 추가 매수 X (이미 비싸게 샀음)
- 손절 X (펀더멘털 자체는 강함)
- 12~24개월 보유 후 재평가
- 이 6주는 **별도 계정**으로 분리. "공부 비용 + 적금"으로 명명
- 다음 개별 종목 매수 시 이 5단계 점검 적용
